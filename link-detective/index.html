Link Detective

Can you spot a fake web address before it tricks you?

  • 12 web addresses appear, one at a time. A short timer is running.
  • Each one claims to be a familiar page, like a bank login. Tap Safe if the address truly matches, or Fake if a trick is hiding in it.
  • Watch for number-for-letter swaps, extra words, a real name used as a subdomain, wrong endings, http instead of https, short links, and the @ trick.
  • Faster answers and streaks score more. After each choice, a tip highlights the part that gives it away.
  • On a keyboard: A or ← Safe, D or → Fake. You can also swipe the address: left Safe, right Fake.
